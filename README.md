# India Startup Investment Intelligence

An end-to-end data analytics project exploring Indian startup funding patterns, investment trends, industry performance, and geographic distribution.

## Project Overview

This project analyzes historical Indian startup funding data to identify investment trends, compare industries and startup hubs, and summarize disclosed funding activity through interactive dashboards and analytical reports.

## Tools & Technologies

- **Python:** Data cleaning, standardization, and exploratory data analysis
- **SQL / MySQL:** Data storage, querying, and business analysis
- **Microsoft Excel:** KPI summaries, data quality checks, and analytical reporting
- **Power BI:** Interactive dashboard development and data visualization

## Key Metrics

- Total disclosed funding: approximately **$38.07 billion**
- Funding records with disclosed amounts: **2,066**
- Startup names in the dataset: **2,459**
- Average disclosed deal size: approximately **$18.43 million**
- Median disclosed deal size: approximately **$1.73 million**

## Analysis Areas

- Funding trends by year
- Industry-wise investment patterns
- Geographic distribution of funding
- Top startups by disclosed funding
- Investment type analysis
- Funding deal-size distribution
- Data quality and missing-value analysis

## Data Quality Notes

The dataset contains 3,044 records. Funding amounts are missing or undisclosed for 978 records. Funding totals and deal-size metrics therefore reflect disclosed amounts, not necessarily the complete value of all investments.

Startup name variations may also represent the same company under different names.
