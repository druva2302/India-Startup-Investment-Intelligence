## 🎯 Project Objective

The objective of this project is to transform historical Indian startup funding data into meaningful business insights through data cleaning, exploratory analysis, SQL queries, and interactive visualizations.

The analysis focuses on understanding disclosed funding amounts, investment patterns, industry performance, and geographic concentration.

## ⚠️ Data Quality and Limitations

- The dataset contains 3,044 records.
- Funding amounts are missing or undisclosed for 978 records.
- Funding totals and deal-size metrics use records with disclosed funding amounts; missing amounts should not be interpreted as zero.
- The 2,459 unique startup names are based on the available names. Variations in company naming may cause some businesses to be counted separately.
- The dataset represents historical information and should not be interpreted as real-time investment data.
